# BootBridge 配套工具

BootBridge 将作为 H3C-NX30-Uboot 的配套组件在本仓库维护，独立构建与发布。本次先发布 U-Boot，工具页暂保留进度说明，没有 EXE、DAT、桥接 BIN 或工具源码下载。

既有离线工具和对应受控验收记录由维护者保留。本次暂缓公开工具，是为了继续完善官方服务器获取最新版 BIN、OTA 与界面；不表示离线工具从未完成过验收。

## 后续工作

| 项目 | 计划 |
|---|---|
| 官方固件 | 实时查询并下载适用的官方最新 BIN，核对完整原件 |
| 桥接生成 | 按已适配的精确来源规则生成完整桥接 BIN |
| 设备识别 | 设备端自动选择处理程序并执行安装检查，用户不手选 HW |
| OTA | 完善升级能力，具体更新对象与行为随工具版本说明发布 |
| 界面 | 改进版本、下载、适配状态与安装流程的展示 |

“官方最新版可下载”和“该版本已有桥接规则”分别展示。新版本尚未适配时，可以下载官方原件，但不能据此放行桥接生成或安装。

工具版本与 U-Boot 版本分别管理，候选和规则通过精确摘要关联。工具更新不自动授予设备 U-Boot 自更新资格；后者本轮仍未开放。

首发交付与安装边界见[安装说明](../../docs/INSTALLATION.md)。
