# BootBridge 离线版 GUI 代码审阅 · 第 1 轮

- 审阅对象：`desktop/gui/offline_main.c`（1646 行）及相关契约测试、生成器、构建脚本
- 依据：`design/desktop-offline-ui/UI-HANDOFF.md`、`prototype.html`、`strings.json`、`screens/*.png`
- 方式：静态代码审阅（沙盒无 Windows/Wine，未实际运行 EXE）。行号以审阅时的版本为准。

## 0. 结论

构建链、核心安全语义都做对了：catalog 校验、SHA-256 精确匹配、guide_model 与 bundle 选择隔离、epoch/取消/关闭语义、导出由引擎校验输出摘要（`bb_export.c:241`）、`CREATE_NEW` 不覆盖、URL 白名单、PE 导入白名单、诊断信息脱敏。契约测试的调整也合理。

**但界面层有多处一打开就能看到的 bug，还不能交给用户实机验收。** 下面的 P0 必须先修。

## 1. P0：一打开就能看到 / 功能错误

| # | 问题 | 位置 | 修复要求 |
|---|------|------|----------|
| P0-1 | **启动时 DPI 固定 96**：`static int dpi = 96`，只在 `WM_DPICHANGED` 更新。笔记本常见 125%/150% 缩放下，整个界面按 100% 画，字很小；初始窗口 1040×700 也没有按 DPI 放大，`AdjustWindowRectEx` 也不感知 DPI。 | 118、1616–1637 | 创建窗口前用主显示器 DPI（`GetDpiForSystem`/`MonitorFromPoint`+`GetDpiForMonitor`，动态加载以兼容旧系统），`WM_CREATE` 中改用 `GetDpiForWindow(hwnd)`；窗口尺寸按 DPI 缩放，并用 `AdjustWindowRectExForDpi`（可用时）。 |
| P0-2 | **初始窗口没有按工作区收缩**：1366×768@125% 等屏幕放不下，最小尺寸 S(920)×S(640) 甚至超过工作区。 | 1489–1494、wWinMain | 初始尺寸 = min(设计尺寸×DPI, 工作区的 90%)，并居中；`ptMinTrackSize` 也要不超过工作区。 |
| P0-3 | **每一页顶部都显示字面量 “第 {n} 步 · 共 6 步”**：`eyebrow()` 把字符串表当 `swprintf` 格式串，但文案里是 `{n}`，没有 `%d`。把外部文案当格式串本身也不安全。 | 611–616 | 不要用文案做格式串；`format_w` 增加 `{n}`，或单独写占位符替换函数。 |
| P0-4 | **第 5 步第 2 行显示 “选择 {f}。”**：`format_w` 只支持 `{m}`/`{v}`，不支持 `{f}`。 | 145–161、974 | `format_w` 改为通用的命名占位符替换（`{m}{v}{n}{f}`），遇到未知占位符时测试直接失败。 |
| P0-5 | **`<u>…</u>`、`<b>…</b>` 原样显示**：`dropS`、`s3warn`、`s6backup` 带标签，生成器没有剥离，代码也没解析。 | gen_ui_strings.py、779、848、989 | 二选一：① 生成器剥离标签，并分成 `xxx_strong` + `xxx_rest` 两段，C 里用粗体/下划线字体分段绘制（推荐）；② 写一个只支持 `<b>`/`<u>` 的极简分段绘制。契约测试要断言生成的头文件里没有 `<`。 |
| P0-6 | **自动换行的段落被裁掉**：`paragraph()` 用 `DT_CALCRECT` 量高度，但 `draw_text(..., line_height>0)` 只按 `\n` 拆行，并把每行画进一个高 = line_height 的矩形；`DT_WORDBREAK` 自动换出的第 2 行起看不到。英文 lead、步骤说明、警告条都会受影响。 | 444–486、599–610 | 改成自己按宽度断行（`GetTextExtentExPointW` 逐行测量，中文按字、英文按词），每行按 line_height 排版；返回真实高度。不要再依赖 `DT_WORDBREAK`+固定行矩形。 |
| P0-7 | **“已自动切换机型”的提示逻辑错误**：提示写在 FILE_REJECTED 分支，而被拒时 `state.bundle == NULL` → `bundle_matches_guide()` 返回 0 → **每次文件被拒都会提示“已识别为 X 的官方固件，已自动切换机型”**；并且在绘制函数里改 `state.auto_switched`。真正切换机型的 `job_done` 反而不设置这个标志，匹配成功时永远不显示提示。 | 833–838、1408–1420 | 在 `job_done` 里记下 `old_model`，`new_model != old_model` 时设 `auto_switched=1` 并 `save_ini()`；提示只在 FILE_MATCHED 分支、且 auto_switched 为真时显示；绘制函数里不得修改 state。 |
| P0-8 | **设置弹窗打开时背景仍可点击**：`hit_element()` 会命中所有已注册元素，弹窗外的步骤导航、按钮仍能点；Tab 也会走到背景元素。遮罩是不透明近黑色（原型为半透明）。 | 584–590、1069–1073 | 弹窗打开时只命中/聚焦弹窗内元素，点击遮罩关闭弹窗；遮罩用 `AlphaBlend` 画 45% 透明（或先画背景，再用预乘位图混合）。 |
| P0-9 | **焦点框跟随鼠标点击，且跨页错位**：`WM_LBUTTONDOWN` 设置 `state.focus = hit`，所以每次点击都会出现青色焦点框；元素数组每次重绘都会重建，换页后 focus 下标指向别的元素，**按空格/回车会触发新页面里同下标的另一个按钮**。 | 1502–1508、1567–1586、1057 | 鼠标点击不显示焦点框（仅键盘 Tab 后显示，类似 :focus-visible）；用（kind, index）记录焦点，而不是数组下标，换页/重绘后重新定位，找不到就清空；支持 Shift+Tab。 |
| P0-10 | **滚动只在第 3、6 步开启**，滚动上限是 `content_height`（应为 content_height − 可视高度）。英文、窄窗口或高 DPI 下，其他步骤会被截断且无法滚动；第 3/6 步能滚到空白处。 | 657、1518–1529、1035 | 所有步骤都按内容高度决定能不能滚；`max_scroll = max(0, content_height − viewport)`；`WM_SIZE` 后重新钳位；画一个细滚动条（原型是 8px 圆角滚动条）。 |

## 3. P2：视觉还原（对照 screens/*.png）

1. **圆角与图标用 GDI 画，有锯齿**：交接文档建议用 GDI+（`gdiplus.dll` 是系统组件，需要加入 PE 白名单）。至少 RoundRect、圆点、勾选、箭头、进度条端点要抗锯齿。`CreatePen(PS_SOLID, S(1.75))` 被截成 1px。
2. **侧栏规则状态圆点**创建了画刷但没有 `SelectObject`，`Ellipse` 用的是当前画刷（可能是空心）；画刷也没删除（GDI 泄漏）。（696–697）
3. **glyph 10（FAQ 折叠箭头）** 开头没有 `MoveToEx` 就直接 `LineTo`，会从上一次的画笔位置拉出一条杂线。
4. 拖放区：实线边框 + `PS_DOT` 点线叠在一起，悬停时青色边框被盖住；规格是 1.5px 虚线、悬停变青色 + 浅底。
5. 选中的机型卡片是 1px 边，规格是 2px teal + tint 底。
6. 别名胶囊的位置用 `wcslen × S(10)` 估算，没有测量文字宽度，中英文都会错位。（725）
7. Logo 画成字母 “B”，应按原型的图形标记绘制（或用 resources.rc 里的图标资源）。
8. 第 2 步 `!rules_ok` 时禁用“下一步”，可以保留，但侧栏步骤仍应可点（交接里写的是“步骤可自由跳转”）。

## 4. 已核实没有问题的部分

- `{ver}` 替换：生成器把 `0.3.0` 换成 `{ver}`（5 个字符），C 里 `p += 5` 是对的。
- 输出 SHA-256：界面显示的是 plan 里的预期摘要，但引擎在 `bb_export.c:241` 已经按实际写出的字节做过校验，失败会返回错误，所以显示值可信。
- 导出用 `CREATE_NEW`，不会覆盖已有文件。
- `WM_CLOSE` 在任务进行中会先取消/等待，再销毁窗口。
- 切换机型（`set_model`）会清掉已选文件，guide_model 不参与 bundle 选择。

## 5. 规格修订（同步到 UI-HANDOFF.md 的理解）

- 920×640 是**设计最小值**，不是硬性值：实际最小尺寸不得超过当前显示器工作区；所有步骤的内容区都必须能滚动。
- 所有文案占位符统一为 `{m}`（机型名）`{v}`（版本）`{n}`（步骤号）`{f}`（文件名）`{ver}`（程序版本）；`<b>`、`<u>` 是唯一允许的内联标记。
