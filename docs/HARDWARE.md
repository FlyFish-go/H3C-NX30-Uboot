# NX30 家族与硬件范围

目前主要围绕 NX30、RT3000、RX3000、RC3000、RW3000 的相关硬件变体维护源码与候选。商品型号用于资料导航；可刷资格仍由具体硬件、NAND/ECC、启动链、布局与精确镜像决定。

## 内部硬件分类

| 分类 | 已有样机中的主要结构 | 资料示例 |
|---|---|---|
| HW-A | IPQ5018、外置 DDR、QCA8337 路线 | 部分 RT3000、RC3000；RW3000 有研究归类，器件资料仍待补齐 |
| HW-B | IPQ5000、集成 DDR、QCA8337 路线 | 部分 RT3000、RC3000 |
| HW-C | IPQ5018、外置 DDR、RTL8367S 路线 | 部分 RT3000、RX3000 |
| HW-D | IPQ5000、集成 DDR、QCA8337 路线，PCB 与布局单独处理 | NX30、部分 RC3000；当前实测对象是采用 Winbond NAND 的 NX30 测试样机 |

这些示例来自已有样机资料，不是所有商品变体的穷尽规格表。HW-B 与 HW-D 有相同主芯片，也不能据此合并镜像。RW3010 目前只作为研究资料，不加入本轮发布映射。

## 本轮候选与实测

| 分类 | 本次镜像状态 |
|---|---|
| HW-A / HW-B / HW-C | 各有独立候选，离线构建与包核对已完成，本轮实机未测 |
| HW-D | 精确候选只在一台 NX30 测试样机上通过有限完整流程：Winbond EF:BA:21、spare64/ECC4、R012 SBL |

四类文件用于源码与候选追溯，不代表任意一个商品都存在或适用四种硬件。后续工具的商品与处理程序映射也是软件规则，不等于每种组合已通过硬件验证。

本次 D 的具体参数、起始条件和结果见[验证记录](VALIDATION.md)，各候选摘要见[硬件范围清单](../release-metadata/uboot-v0.1.0-pre.1/HARDWARE-SCOPE.json)。

## 用户如何识别

正式配套流程不要求用户手选 HW-A/B/C/D。主机核对官方原件的完整文件身份，桥接程序在设备上依据运行时事实选择处理程序，再执行全部安装检查。未知、矛盾或多重匹配时停止。

这一流程的工具本次尚未发布。外壳、背标、PCB 板印、machid 或 NAND ID 均不能单独替代兼容核验。
