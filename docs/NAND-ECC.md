# NAND 与 ECC 状态

当前新版的完整实测覆盖一台采用 Winbond NAND / ECC4 的 NX30 测试样机：EF:BA:21、page2048、spare64、ECC4、R012 SBL。其他 NAND 和新版 ECC8 安装仍需独立验证。

| 层次 | 已有内容 | 本轮结论 |
|---|---|---|
| NAND 目录 | 19 组型号/ID、20 种几何配置的离线资料与核对 | 不等于全部条目实机通过 |
| 驱动与格式 | ECC4/ECC8 对应配置；限定 C8:41、spare128 路径的双模式机制 | 不保证任意 NAND 切档或任意混读 |
| 当前 D 测试样机 | Winbond spare64/ECC4 的安装事务、原厂接管、冷启动与完整读回 | 仅该精确样机与镜像通过 |
| 新版 ECC8 | 本轮未完成实机安装及冷启动验收 | 待测试 |

保留设备现有 ECC4 格式是适配方向，不要求先重编码到 ECC8。需要分别核验前级加载 APPSBL、APPSBL 的存储格式、运行后读取启动与系统数据，以及 Linux 接管后的格式。

NAND ID 匹配或某个分区可读，不能独立证明整条启动链兼容。spare、控制器暴露的 OOB 和可用 OOB 也不是同一个参数。

当前 spare64 候选不套用旧 C8:41/spare128 的双模式资格。本项目尚未证明不同分区或逐页任意混用 ECC4/ECC8。
