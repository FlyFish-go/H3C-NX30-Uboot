# 本次交付与安装说明

首轮交付为 U-Boot 源码和四类精确分区候选，适合源码审阅、构建研究与已有独立恢复流程的指定测试者。BootBridge 工具将在本仓库后续发布，本次没有普通用户的首次安装入口。

## 普通用户

请等待配套工具和对应指南。**`appsbl.partition.bin` 不是原厂升级页接受的完整固件，不能直接上传。** 源码归档里的 MBN 或其它候选也不能当作官方升级 BIN 使用。

## 测试者

只有已经具备覆盖自己精确样机的安装、备份和恢复流程，才进入测试。核对候选摘要、实际硬件、NAND/ECC、前级启动链与物理目标；这些信息无法唯一确定时停止，不套用别台机器的偏移或写入命令。

HW-A/B/C/D 目录只用于追溯。相同商品名、主芯片、NAND ID 或 PCB 板印不足以决定安装资格。本轮 D 的结论只对应[验证记录](VALIDATION.md)中的 采用 Winbond NAND 的 NX30 测试样机。

## 后续配套流程

工具识别完整官方原件并导出已适配的桥接 BIN；用户通过原厂升级页上传该完整文件。桥接启动后自动识别运行条件、提供备份并执行完整安装检查，通过后才提供安装确认。普通用户无需选择 HW-A/B/C/D。

这一流程的工具尚未在本次发布中交付。官方最新版可下载也不表示已具备对应桥接规则，进度见[工具页](../tools/bootbridge/README.md)。

## 恢复与反馈

已安装本版 U-Boot 后，按住 RESET 上电进入 U-Boot 维护网页，不按则启动默认系统。也可以通过 UART 截停启动后输入 `httpd` 进入维护网页。

恢复依据是自己的写前备份和精确样机流程。本次不提供可供所有变体共用的恢复镜像，也不把 ECC 解码数据备份当作带 OOB/ECC 的编程器原始镜像。

使用[测试记录模板](TEST-REPORT-TEMPLATE.md)提交去敏结果。恢复包可能含设备身份、ENV、ART 和认证材料，应保存在本地私有位置。
